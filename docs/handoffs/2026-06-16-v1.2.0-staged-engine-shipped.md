## Lessons (carry forward)
- **Dogfooding is the only thing that found these.** Three engine bugs (#696/#698/#699), each invisible to unit tests (which pre-populate `last_result`/`scope.tier` and drive `_apply_events_to_store` directly, never reconcile's router). Always dogfood a behavior change on a real ticket before trusting it.
- **Don't over-trust the first root-cause.** #663 was diagnosed as #696 (tier), fixed + green-tested — and STILL blocked. The real cause was #698 (reconcile's router pre-empting the advance machine). When a fix "should" work but the symptom persists, re-diagnose from real data (Abigail oath: stop at debugging depth 2+).
- **Two routers for one decision is a latent bug.** The advance machine and reconcile's `_apply_sentinel_to_task` independently routed tasks; unifying them (#698) was the fix. Watch for other dual-authority paths.
- **A failed sentinel ≠ failed work.** #475's and #663's IMPL stages produced *correct code* and only failed on sentinel emission. Inspect the branch before re-running — salvage beats redo.
- **Skills that drive the cw CLI live in THIS repo, published to `~/.claude` on install.** Never mass-prune the shared `~/.claude` namespace — manifest-scope it. global-claude carries no cw skills.
- **Verify world-state via the real artifact**, never `--version` (it lagged for the whole prior session) or queue status alone.
