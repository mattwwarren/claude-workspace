How we got here

It started with a tool that was being a bum.

The day before, I tried to dogfood cw — the multi-session orchestrator this repo is — and it misbehaved. State got clobbered. Failures vanished silently. Worktrees got force-removed with unsaved work in them. Classic "the tool I built to run agents can't reliably run agents" energy.

Instead of one-off patching, I turned the frustration into a reliability sweep: five parallel audits, each hunting one defect class — unsynchronized state writes, silent failures, worktree/git safety, parser false-rejects, event-bus edges. That sweep produced a manifest: 13 tickets across 4 waves, with the same-file collisions mapped so they could be dispatched safely. Then I handed it the keys and went to bed.

The operating model

One orchestrator. Many disposable hands.

The main session never wrote feature code. It stayed clean and coordinated — spawning a fresh isolated agent per ticket, enforcing a hard barrier between waves, and gating every merge behind its own review.
